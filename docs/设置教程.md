# AIkey 2.5.8 设置教程

## 在原加载目录升级
将本版本文件复制到你原来加载的插件文件夹，内部版本号为2.5.8。
在Chrome扩展管理页面找到原来的AIkey，点“重新加载”，再刷新Google Cloud页面和工作台。
保持原文件夹、原Chrome配置和原扩展，不要移除后重装。扩展原来保存的表格地址、同步密钥、账号、余额和监控设置会保留。
首次从Token旧版迁移时会停用旧Token监控、旧费用估算保护及旧到期关闭授权。升级到2.5.8不会重置现有配置，也不会扩大旧的“仅项目”授权。保护是否启用，始终以工作台顶部的余额停用状态为准。
请先保留原源码，并导出配置JSON。源码备份与Chrome本地配置备份用途不同。

## 最低余额只在03设置
连接Google Cloud并选择账号，在03填“最低余额”，例如30，保留“同时关闭整个结算账号”，点“1. 核对项目与结算账号（不启用）”。按各账号原币种比较，不需要单价、模型或汇率。
保存金额不会启用停用。第1步会只读核实账号、全部关联项目、Key/AI服务/项目结算停用权限、账号关闭权限及当前余额，不停用任何服务。
在第2步核对完整结算账号ID、项目范围并勾选授权，点击第2步确认启用联合停用，才会执行自动停用。当前余额已经≤最低金额时，启用就可能立即停用，请先核对。
联合流程先撤销列出项目的Key、禁用Vertex/Gemini服务并解除项目结算，再打开官方管理页关闭整个结算账号。与日期倒计时无关，余额达到停用线即开始执行。
项目与账号结果分开显示：只点了关闭按钮、只解绑、只停API都不算全部完成。只有项目安全停用及结算账号关闭都核实，才显示“项目与结算账号均已停用”。
默认不授权删除项目。只有另外勾选时，且已选措施尝试后仍不能核实项目停用，才会处理列出的对应项目。结算账号关闭影响它的全部关联项目；发现新增未授权关联项目会停止自动关闭并提示重新核实，不扩大处理范围。
官方页面若因欠费、付款资料、权限或账号类型阻止关闭，插件会显示未完成，不会强行绕过条件。只有明确未提交的失败可按按钮重试，结果未知时需在官方页面核实。
关闭前费用仍需结清，预付款充值余额可能作废，退款及银行卡仍在官方页面处理。
顶部“联合停用已启用”才表示项目与整个结算账号都已纳入当前授权。若显示“已启用（仅项目）”，旧授权还未包含结算账号，需先暂停，再重新检查和授权。只保存金额、只读检查或启用日期关闭，都不代表余额保护生效。
最低余额规则使用“余额≤金额”，默认30，允许设0。按日期关闭整个账号仍是独立的可选功能。

## 一键备份，以后不用重填
先保存需要的最低余额、表格设置等，再到工作台底部“配置备份”，点“一键导出已保存配置”。
JSON包含：表格链接、Apps Script部署地址、表格同步密钥、各账号最低余额、账号选择、余额监控偏好和可选到期日期。
它不包含Google登录Cookie、Google API Key或服务账号私钥。同步密钥本身也有写入表格的权限，所以JSON只留在本机，不要公开上传GitHub、聊天群或网盘。
换浏览器或重装后：点“导入配置”，选JSON，核对预览，点“导入以上配置”。无需重新输入各项内容。导入的余额只标为历史记录，先重新连接读取。
导入后自动停用和到期关闭均关闭；表格自动发送也关闭。勾选“每分钟自动同步”并点击“保存并授权同步”即可用恢复的地址和密钥继续同步，不用重填。
每个Chrome配置的数据独立。如管理多个浏览器，分别导出并用容易区分的文件名保管。

## 现有表格升级，保留已有资料
已经有管理表格：继续用原表，不要用空白模板替换。
从该表菜单“扩展程序→Apps Script”打开绑定脚本，把原AIkey代码替换为附带的support/Google表格同步.gs完整内容。旧版AIkey的同名函数和云端Token停用脚本不要重复保留，以免旧函数覆盖新函数；其他与AIkey无关的自用代码请保留。
按support/appsscript.json更新清单。新脚本不需要cloud-platform或外部网络请求权限，只需表格、表格菜单及管理本脚本触发器的权限。
运行 setupAIkeySync 一次并完成Google授权。它保留原同步密钥、自动备份现有表格、隐藏旧Token列并添加简洁保护列。邮箱、Key、联系人、扣款资料保留；剩余天数、到期状态、数据状态公式会升级。
如果旧云端保护触发器名为runAIkeyCloudGuard，初始化会将这一旧触发器移除。其他触发器不会删除。
部署→管理部署→编辑原Web应用部署→选择“新版本”→部署。沿用原部署就能保留原/exec地址，插件不用重填。
若你新建了另一个部署，需在插件里换成新的/exec地址；同步密钥仍沿用当前脚本属性里的值。
回插件先点“立即同步”。确认显示同步成功、匹配行数大于0、保护设置行数大于0，并且没有“更新Apps Script”的提示。
若有“未匹配账号”，在管理表的“结算账号ID”列填对应ID，一行一个Key，多行共用同一账号的余额。
若没有同步配置，表格菜单“AIkey同步→查看同步密钥”可查看。它与Google API Key不同。

## 全新表格才用空白模板
附带AIkey简洁管理台账-v2.5.6.xlsx，保留AIkey管理工作表名称和第7行标题。
导入Google表格后，浅黄格填写邮箱、联系人、项目ID、结算账号ID、Key、扣款等个人管理资料；同步不会自动收集这些私人资料。
浅蓝格是采集/计算区域。最低余额及联合停用状态由插件03保存后同步；直接改表格数值只影响显示，不会远程配置插件或执行停用。
颜色按账号原币种：≤100淡黄色，≤80黄色，≤50淡红色，≤该行最低余额为停用警示色。颜色不代表已经启用或已经停用，请看“余额保护状态”和“项目处理结果”。
同一结算账号的多个Key共用余额，不能把多行余额相加。
页面只显示整数天数时，仅显示约剩天数，不捏造准确到期时刻。你手填的准确到期日期不会被页面天数覆盖。

## 更新间隔与使用限制
余额后台约每30秒检查采集，约每分钟重载专用结算概览页，Google页面本身可能有延迟。
“最近余额读取”表示插件读了页面；“余额采集时间”表示采用的页面快照；“金额变化记录”只有余额改变才更新。金额没变化也会刷新真正的新页面快照时间。
表格启用后约每分钟发一次现有快照。同步时间更新不代表Google余额刚更新。超过5分钟的余额快照会明确标记。
余额保护启用后约每30秒核对，只使用最近5分钟内、币种和账号匹配的官方页面余额。未知、手动或过期余额不作为自动停用依据。
Chrome需要运行、扩展启用、Google登录有效且具有权限。关闭浏览器、退出登录、Google页面或接口改变会影响运行。
移除了Token估算后不再按消耗速度预测提前停用。此版依赖页面显示的赠金余额，不能把付费账单、信用卡额度当作赠金余额，也不能保证实时零超额；按你的消耗情况留更高余额缓冲。
表格脚本只接收签名数据，不执行Cloud停用、关闭账号、删除项目、退款或银行卡操作。

表格与插件的配置需在自己的Google账号下完成，启用保护前请核对目标账号、最低余额和已授权项目范围。

## 2.5.8升级提醒
必须在扩展管理页重新加载整个AIkey扩展，再刷新工作台和Cloud页面。只刷新工作台可能仍在使用旧后台，插件会拒绝把旧后台的“仅项目检查”当作联合关闭授权。
原表格模板及签名同步结构没有变化，继续使用support中现有简洁版文件，无需新建或覆盖台账。
