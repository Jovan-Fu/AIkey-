# 结算绑定或配置中途失败

Precondition check failed是Google返回的前置条件错误，不能只凭该文字判断是银行卡、额度或插件问题。

1. 保留日志中已创建的项目ID，避免反复新建项目。
2. 在同一个Google账号的官方控制台选择该项目，查看结算账号的付款、身份验证、账号状态和关联权限提示。
3. 回工作台展开“一键配置”下方的“配置中途失败？检查并接续现有项目”，填入自己的项目ID并接续。例如格式为ai-20000101-abcdef，该示例不代表你的项目。
4. 插件会核实项目身份与绑定关系。已正确绑定的步骤会跳过，已存在的服务账号及同名API Key会核验后复用；JSON私钥生成结果不确定时不会自动重复提交。
5. 如官方页面仍要求验证或显示限制，请先在Google处理。插件不能绕过账号限制或自动换绑其他结算账号。

“Service Account not found”也可能发生在刚创建服务账号后的同步过程中。插件只对明确不存在的拒绝做有限重试；网络结果不确定时会保留任务供核实。

“复制错误诊断”会包含正在排错的项目及结算标识，分享前请自行隐去个人资源名称。不要分享API Key、Cookie、同步密钥或JSON私钥。
