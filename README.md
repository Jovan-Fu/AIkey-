# AIkey后续流程一键申请

<img src="icons/AIkey-logo.png" width="96" height="96" alt="AIkey">

Chrome扩展，辅助完成Google Cloud项目配置、赠金余额采集、最低余额保护和Google表格同步。当前版本 **2.5.9**。

## 主要功能

- 连接已登录的Google Cloud账号，新建项目、关联结算、启用服务、创建API Key及下载服务账号JSON私钥。
- 读取结算概览、账号管理页和可核实项目页中的试用赠金余额与剩余天数。
- 在03设置最低余额，默认30，按账号原币种比较。余额≤最低金额时，按已授权范围停用项目并关闭整个结算账号。
- 余额≤100、≤80、≤50分别使用淡黄、黄、淡红提示，达到最低余额显示停用警示色。
- 将余额、天数、最低余额与保护状态同步到自己的Google表格。
- 一键导出、导入配置，保留表格链接、部署地址、同步密钥和各账号最低余额。

## 安装与升级

首次安装：下载并解压本版本，在Chrome扩展管理页打开开发者模式，选择“加载已解压的扩展程序”，选择含manifest.json的文件夹。

升级已安装版本：将新版插件文件复制到**原来的加载目录**，在扩展管理页对原AIkey点击“重新加载”，再刷新Cloud页面及工作台。保持同一个Chrome配置、扩展和加载路径，可以沿用本地设置。升级前建议先导出配置。

首次从Token旧版迁移到简洁余额版时，会停用旧Token监控、旧费用估算保护和旧到期关闭授权。原有表格地址与同步密钥保留。2.5.6/2.5.7/2.5.8升级到2.5.9保持当前配置与授权状态。旧的“仅项目”授权不会自动扩大为关闭整个结算账号。要启用联合停用，需暂停旧规则后重新核对范围并授权；已触发的旧任务不会通过保存而清除，新增账号关闭可在官方管理页处理。

2.5.9补上新版中文“免费试用状态：剩余 $300.00 赠金和 78 天时间”横幅解析。新浏览器或导入配置后没有旧标签页ID时，已连接且启用自动刷新的账号会建立自己的后台概览采集页，无需等待手工登记。此过程只读，不会启用停用规则；关闭自动刷新或未连接目标Google账号时不会自动建页。

重新加载扩展会清除当前浏览器会话中的配置结果和登录连接，先确保JSON私钥已经下载保存，再重新加载并连接Cloud。表格地址、同步密钥和最低余额保留；新浏览器可导入私下保存的配置文件，导入后自动授权保持关闭。

详细步骤见[设置教程](docs/设置教程.md)，中途绑定失败见[结算故障处理](docs/结算故障处理.md)。

## 使用步骤

1. 从已登录的目标Google Cloud页面打开工作台，连接并选择结算账号。
2. 在03读取余额，设置最低金额，保留“同时关闭整个结算账号”，点击“1. 核对项目与结算账号（不启用）”。只读检查不会停用项目。
3. 核对第2步列出的关联项目，填写完整账号ID并勾选授权，点击“2. 确认并启用按余额停用”。当前余额已≤最低金额时，启用会立即开始停用。顶部必须显示“联合停用已启用”，且范围包含整个结算账号。按日期关闭的“已授权”不代表余额规则生效；达到余额阈值后不会等待日期。
4. 如需表格同步，按教程配置[完整Apps Script](support/Google表格同步.gs)及[脚本清单](support/appsscript.json)。已有表格继续原地升级；新表格使用[空白模板](support/AIkey简洁管理台账-v2.5.6.xlsx)。

## 更新频率与保护范围

浏览器运行且登录有效时，后台约每30秒检查采集，专用结算概览约每分钟刷新，启用表格同步后约每分钟发送一次已有快照。Google页面及入账本身可能延迟，快照超过5分钟会提示过旧。

最低余额保护只采用账号、币种匹配且最近5分钟内的官方页面余额。手动、未知或过期金额不触发。此版已移除Token计价与消耗速度预测，不能保证实时零超支，需按消耗情况预留余额。

联合停用按顺序撤销Key、暂停Vertex/Gemini相关AI服务并停用项目结算，再通过Google官方管理页关闭整个结算账号。项目停用与账号关闭分别显示状态，两项都通过接口核实后才显示全部完成。关闭页出现欠费、权限或其他限制时会显示未完成；提交结果不确定时不会反复点击。

删除项目须另行明确授权，默认关闭，且只在已选停用措施尝试后仍不能核实项目停用时作为最后手段。按日期关闭是独立的可选功能。浏览器关闭、登录失效、权限不足或Google页面变化均可能影响执行。关闭前已产生的费用仍需结清；预付款充值账号的未用额度可能作废。[Google官方关闭说明](https://docs.cloud.google.com/billing/docs/how-to/close-or-reopen-billing-account)、[Cloud Billing接口字段限制](https://docs.cloud.google.com/billing/docs/reference/rest/v1/billingAccounts/patch)。

## 配置与隐私

导出的配置JSON包含表格同步密钥，应在本机私下保管。仓库只提供源码和空白模板，不应上传导出的配置、完整API Key、JSON私钥、Cookie或填写了个人资料的台账。GitHub网页直接上传文件不会按.gitignore自动过滤，请只上传整理好的源码目录。

导入配置后，自动停用、到期关闭和表格自动发送保持关闭。核对后勾选每分钟自动同步并保存，即可使用恢复的地址和密钥，无需重填。

表格通过HMAC签名接收余额快照，不接收完整Google API Key、私钥、Cookie及联系人信息，也不执行Cloud停用、退款或银行卡操作。用于API调用的服务账号权限及全部扩展访问范围可在源码和manifest.json中查看。

## 开发验证

在仓库源码目录（含tests文件夹）中使用Node.js 24运行：

```sh
npm test
```

测试使用模拟Cloud响应，不连接真实Google账号，不执行真实关闭或项目删除。相关本地验证覆盖联合停用、关闭票据、提交前复核、两部分结果核验、旧授权隔离及配置恢复。真实账号的实际关闭需按自己的账号权限及Google页面结果核实。
